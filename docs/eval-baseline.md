- 편집(대안 선택·재정렬·삭제)은 저장 때의 판정 입력(`plan_context`)으로 다시 판정한다. 조정 필요를 풀 수만 있고 새로 걸지 않는다. 안내는 편집 뒤 일정 기준으로 다시 만든다. 관문 이전 일정은 `plan_context`가 없어 다시 판정하지 않는다.
- 안내는 HARD·CORE 위반만 "N일차 …" 문장으로 만든다. SOFT 중 이른 종료는 출발 시각을 모르는 마지막 날에만 출발 시간을 알려 달라는 제안이 된다. `InvariantChecker.summarize` 안내 가운데 이동 거리("다소 깁니다"), 늦은 종료, 긴 공백, 마지막 날이 아닌 날의 이른 종료, 도착·출발로 짧은 날의 관광 없음은 더 나오지 않는다. `summarize`는 내부 위반 라벨("day1 점심 없음")만 돌려준다.
- 첫날 23시 이후 도착이면 허브와 숙소 시각이 23:59 상한에서 1분 겹쳐 구조 검증이 매번 실패했다(관문 이전에는 그대로 저장). 앞 스텝 끝을 다음 스텝 시작으로 당겨 해소했고 replay 스텝은 변하지 않는다.
